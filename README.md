# Portfolio Website

A personal portfolio website built with Next.js, React, TypeScript, Tailwind CSS, and Motion.

This project showcases my profile, technical skills, featured projects, and contact information as a Backend / Fullstack Developer.

## Overview

This portfolio website is designed to present my developer profile in a clean, modern, and responsive layout.

It includes personal introduction, skills, services, selected projects, dark mode support, animations, and a contact form.

## Live Demo

* Website: https://nguyen-van-nghiem.vercel.app

## Features

* Responsive portfolio layout
* Hero section with typewriter effect
* About section
* Skills showcase
* Services / expertise section
* Featured projects section
* Contact form integration
* Dark mode support
* Smooth UI animations
* Mobile-friendly navigation

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Motion
* Web3Forms
* Vercel

## Purpose

This project is used as my personal developer portfolio and online profile.

It helps recruiters, hiring managers, and collaborators quickly review my skills, projects, and contact information.
