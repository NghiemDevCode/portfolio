# Portfolio
A sleek, high-performance developer portfolio built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**.
---
##  Key Features
- **Smart Dark Mode**: Context API driven theme switching.
- **Fully Responsive**: Optimized for all device sizes.
- **Smooth Animations**: Interactive UI powered by Framer Motion.
- **Dynamic Case Studies**: Professional 5-point project analysis layout.
##  Tech Stack
- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Assets by Icons8](https://icons8.com/)
